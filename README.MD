Projeto de lista de tarefas moderna desenvolvido com HTML, CSS e JavaScript puro.

##Funcionalidades
- Adicionar tarefas
- Concluir tarefas
- Excluir tarefas
- Filtros de tarefas
- Persistência com LocalStorage
- Dark Mode
- Drag and Drop
- Animações suaves
- Contador de progresso

##Tecnologias utilizadas
- HTML5
- CSS3
- JAVASCRIPT
- LocalStorage API
- SortableJS

#Conceitos Praticados
- Manipulação do DOM
- Eventos
- Renderização dinâmica
- Gerenciamento de estado
- Persistência de dados
- Arrays e métodos avançados
- CSS Variables
- Responsividade
